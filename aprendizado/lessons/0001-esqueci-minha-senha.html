Licao 1: o fluxo de esqueci minha senha de ponta a ponta

Foco: entender o caminho completo do link por email, em que cada decisão protege algo específico.

O problema

O usuário não lembra a senha. Nada no app permite entrar, e nunca é seguro "enviar a senha" por email, pois o app não guarda senha em texto. A saída é provar pelo email que ele é o dono da conta e deixá-lo criar uma senha nova.

Os 7 passos da jornada

1. Usuário pede recuperação. Na tela de login, o link "Esqueci minha senha?" abre o FormularioRecuperarSenha.tsx, que chama POST /api/auth/esqueci-senha (rotas em klok-api/rotas/auth.js).
2. O servidor gera o token. Em esqueciSenha no klok-api/controladores/auth.js o servidor sorteia randomBytes(32), ou seja 32 bytes aleatórios (256 bits de entropia). Guarda no banco apenas sha256(token), com expiração de 30 minutos.
3. Resposta genérica. Devolve sempre o mesmo texto, exista ou não o email. Se o email não existe, ninguém descobre. Detalhe no glossário: resposta genérica.
4. O link vai por email. klok-api/email.js usa nodemailer quando há SMTP completo no .env. Sem SMTP, loga o link no terminal (fallback de dev). O link montado é URL_BASE + /redefinir-senha/<token>, uma página pública no back-end.
5. Página de confirmação. A rota pública GET /redefinir-senha/:token no app.js serve um HTML com o botão "Abrir o app Klok". O toque dispara klok://redefinir-senha?token=... e abre o app. Se o token for inválido ou expirado, a página avisa.
6. App recebe o deep link. O App.tsx escuta o link via Linking e extrai o token manualmente por indexOf('token='). Renderiza a RedefinirSenhaScreen.tsx.
7. Nova senha e desligamento da sessão. A tela chama POST /api/auth/redefinir-senha. O servidor valida o token (uso único, não expirado), troca a senha com salt e marca o token como usado. Em seguida o app desloga o usuário via aoConcluirRedefinicao, para que ele entre com a senha nova.

Por que cada decisão existe

DecisãoO que protege
Hash do token no bancoSe o banco vazar, ninguém consegue criar links válidos
Expiração de 30 minLimita a janela de ataque de um link perdido
Uso únicoTorna o link imune a reuso depois de usar
Resposta genéricaNão revela quais emails estão cadastrados
Rate limit no endpointReduz tentativa em massa de recuperação
Página HTTPS antes do klok://Gmail e navegador bloqueiam clique direto em scheme customizado; o gesto do botão é permitido

Quiz

  1. Onde o token fica guardado depois que o link é gerado?
  2. Para quantos usos o token vale?
  3. Depois que a senha é redefinida, o usuário fica?
